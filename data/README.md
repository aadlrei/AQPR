# Dataset setup

Datasets are not distributed through this repository. Users must obtain AIROGS-light, HYGD, SMDG, REFUGE, PAPILA, and RIGA according to their respective access and license conditions, then configure `AQPR_DATA_ROOT`.

Do not commit raw images, preprocessed image caches, patient-level manifests with restricted identifiers, or HYGD-derived proxy masks without an explicit redistribution review.
